# statecraft-releases
Statecraft release files. Source and issues: statecraft-app/statecraft.

- **What it is:** the download files of each Statecraft release. No source code and no issues live here.
- **Who owns it:** the Statecraft project (`statecraft-app`). Only the owner makes a release.
- **What governs it:** each release is built from the Statecraft source, and `checksums.txt` lists the checksum of each file.
- **How to run it:** take the newest release from the Releases page of this repo. The install steps are on the Statecraft website.
